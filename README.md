# GhostC

Minecraft 1.8.9 client research and development, with a new modular Java core.

**Status:** Early development. This repository is not yet a playable Minecraft client. Its first implementation is being introduced through a reviewed pull request.

Development focuses on clean-room source, documented provenance, repeatable CI, module lifecycle, profiles and a stable game adapter before gameplay features.

No recovered proprietary donor code, cracked launchers, injected binaries or credentials belong in this repository.
