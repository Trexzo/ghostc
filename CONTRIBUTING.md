# Contributing to GhostC

Implement in reviewable PRs, one coherent milestone at a time. Include exact changed files, test output, compatibility impact, rollback, provenance and known runtime gaps.

**Public repository hygiene:** never upload credentials, proprietary donor sources/assets, cracked clients, injectors or unknown native binaries. The core is a clean-room implementation. Development ideas may come from public feature descriptions, but reproducing a third-party implementation requires permission and license review.

CI is an offline Java test until the Forge adapter is implemented. Use issue checklists to coordinate modules and services. Any "verified" statement must say whether the check was local, CI, Windows or in-game.

Licensing is not yet specified. Do not assume public GitHub visibility grants permission to redistribute code or artifacts.
